# Visual asset prompt scaffold

Write an image prompt for a named production purpose such as identity,
environment, prop, style/lighting, or shot-keyframe inspection.

Shot: {{shot}}

Production bible: {{visual grammar and continuity anchors}}

Asset purpose and selection criteria: {{decision this image must support}}

Delivery constraints: {{runtime constraints}}

Describe only visible evidence: composition, identity anchors, character and
prop state, spatial relationships, lighting/color grammar, texture, and the
decisive moment. Include intentional change and forbid known continuity drift.
Use only dimensions and reference roles declared by the selected image binding.
Do not imply that the result will become a video input unless the selected video
binding declares that role.
